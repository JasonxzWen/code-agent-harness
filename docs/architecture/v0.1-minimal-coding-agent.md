# v0.1 Minimal Coding Agent Architecture

## Problem

项目需要一个 minimal but real coding agent harness：它可以在 repository 内运行，通过 tools inspect files，并生成 grounded answers。

## Design summary

```txt
User Task
→ TUI
→ Agent Controller
→ Provider Client
→ Tool Call
→ Tool Registry
→ Permission Gate
→ Tool Executor
→ Tool Result
→ Provider Client
→ Final Answer
→ JSONL Trace
```

## Components

```txt
apps/cli
  └─ Ink TUI

packages/core

  ├─ ToolRegistry

```

## Core loop

```ts
while (run.status === "running" && step < maxSteps) {
  const messages = buildMessages(runState);
  const response = await provider.generate({ messages, tools });

  if (response.type === "tool_call") {
    for (const call of response.calls) {
      const preflight = await toolRegistry.prepare(call, repoContext);
      if (!preflight.ok) {
        appendToolResult(runState, preflight.result);
        continue;
      }

      const decision = await resolvePermission(preflight.prepared);
      const result =
        decision === "allow"
          ? await toolRegistry.execute(call, { ...repoContext, permission: decision })
          : permissionDeniedResult(preflight.prepared);
      appendToolResult(runState, result);
      eventLogger.write(...);
    }
    continue;
  }

  if (response.type === "final") {
    runState.finalAnswer = response.content;
    break;
  }
}
```

## Trade-offs

| Decision                    | Alternative         | Reason                                |
| --------------------------- | ------------------- | ------------------------------------- |
| Read-only v0.1              | edit-capable v0.1   | 先在写入前证明 runtime safety         |
| JSONL trace                 | SQLite / OTEL       | 更简单、可 inspect、eval-ready        |
| OpenAI first                | full multi-provider | 验证 boundary，避免 adapter work 翻倍 |
| Internal tool protocol      | MCP first           | 保持 core runtime 聚焦                |
| Tool-driven repo inspection | preload whole repo  | 对 context budget 和 grounding 更安全 |

## Boundaries

```txt
apps/cli must not execute tools directly.
packages/core must not import concrete provider SDK types.
packages/providers must not import Ink.
packages/tools must not depend on providers.
Command execution must exist only inside run_command.
Filesystem reads must pass path and secret policy.
```
