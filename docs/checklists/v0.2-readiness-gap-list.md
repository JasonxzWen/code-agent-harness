# v0.2 Readiness Gap List

本清单跟踪 `docs/releases/v0.2.0-contract.md` 中的 release-blocking gaps。v0.2 只有在 P0 项全部关闭、质量门禁通过、发布文档完成后才能 release。

## 范围守卫

| 状态 | 守卫                           | 证据 / 下一步                                                         |
| ---- | ------------------------------ | --------------------------------------------------------------------- |
| [ ]  | 不引入 auto-commit/stage/push  | patch apply 只能修改工作区，不能自动执行 git stage/commit/push。      |
| [ ]  | 不引入 background write        | 所有写入必须发生在当前交互式 run 内。                                 |
| [ ]  | 不宣称 sandbox runtime         | sandbox 是 v0.8 方向；v0.2 只能依赖 patch policy 和 permission gate。 |
| [ ]  | 不引入 persistent memory       | patch approval 不得跨进程持久化。                                     |
| [ ]  | 不引入 product-level subagents | v0.2 保持 single-agent loop。                                         |
| [ ]  | 不引入 MCP integration         | patch tool 是本地内部工具，不是 MCP bridge。                          |
| [ ]  | 不扩展任意 shell 写命令        | 不通过 `run_command` 开放写操作。                                     |
