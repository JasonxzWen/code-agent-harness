# v0.2 Readiness Gap List

本清单跟踪 `docs/releases/v0.2.0-contract.md` 的 release-blocking gaps。只有
P0 项关闭、质量门禁通过、发布文档完成后，`v0.2.0` 才能 release。

## 范围守卫

| 状态 | 守卫                           | 证据                                                                                                    |
| ---- | ------------------------------ | ------------------------------------------------------------------------------------------------------- |
| [x]  | 不引入 auto-commit/stage/push  | `apply_patch` 只调用 `git apply`；`packages/tools/test/tools.test.ts` 验证无 staged diff、无新 commit。 |
| [x]  | 不引入 background write        | 写入只能发生在当前 `runAgentTask` 的 approved tool execution 内。                                       |
| [x]  | 不宣称 sandbox runtime         | README、release note 和 architecture doc 均列为限制。                                                   |
| [x]  | 不引入 persistent memory       | 未新增 memory 存储或 approval persistence。                                                             |
| [x]  | 不引入 product-level subagents | agent loop 仍为 single-agent loop。                                                                     |
| [x]  | 不引入 MCP integration         | `apply_patch` 是本地内部工具，不是 MCP bridge。                                                         |
| [x]  | 不扩展任意 shell 写命令        | `run_command` allowlist 未扩大；patch 写入只在 `packages/tools/src/patch-tool.ts` 内用结构化 argv。     |
