# Development Checklist

## Before coding

```txt
[ ] scope classified
[ ] research note created if required
[ ] spec created if required
[ ] acceptance criteria defined
[ ] non-goals documented
[ ] v0.1 scope guard checked
[ ] release blocker status recorded
```

## During coding

```txt
[ ] relevant files inspected
[ ] package boundaries preserved
[ ] schemas used for external input
[ ] model-generated input validated with strict schemas
[ ] permission policy enforced in code, not prompts
[ ] errors are structured
[ ] tests added or updated
[ ] docs updated if needed
```

## After coding

```txt
[ ] format check
[ ] lint
[ ] typecheck
[ ] build
[ ] test
[ ] smoke
[ ] self-review
[ ] release readiness gap list updated if release criteria changed
[ ] final report
```
