# v0.1 就绪缺口清单

本清单跟踪 `docs/releases/v0.1.0-contract.md` 的 release-blocking gaps。

## 范围守卫

| 状态 | 守卫                                        | 证据                                                                                                                   |
| ---- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [x]  | 不存在 file editing tool                    | `packages/tools/src/index.ts` exports read/search/git status plus restricted `run_command`；没有注册 edit/write tool。 |
| [x]  | 不存在 patch application path               | Repository search 未发现 product patch/apply-patch API。                                                               |
| [x]  | 不存在 persistent memory                    | Product code 没有 memory store；`docs/adr/0007-no-memory-in-v0.1.md` 记录该 non-goal。                                 |
| [x]  | 不存在 product-level subagent orchestration | Product code 不包含 subagent runtime；subagents 仅作为 development workflow infrastructure 文档化。                    |
| [x]  | 不存在 MCP integration                      | Product packages 未 import 或 expose MCP integration。                                                                 |
| [x]  | 未宣称 sandbox runtime                      | Sandbox 只出现在 roadmap/research docs 的 later releases 中。                                                          |
| [x]  | 未引入 eval dashboard                       | Product code 中没有 dashboard package、route 或 UI。                                                                   |
| [x]  | 未引入 IDE extension                        | 不存在 IDE extension package。                                                                                         |
| [x]  | 未引入 background task mode                 | 不存在 background runner 或 task scheduler。                                                                           |
