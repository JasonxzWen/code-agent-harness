# v0.1.0 Release contract：Minimal Coding Agent

## 目标

构建一个可运行、terminal-first coding agent harness。它可以通过经过验证的 tools inspect 真实 repository，并在不修改文件的前提下生成 grounded answer。

## 用户旅程

```txt
User opens terminal
→ runs agent-harness
→ enters task
→ agent starts run
→ provider requests repo inspection tools
→ tool calls are validated and executed
→ tool results are appended to context
→ agent returns final answer grounded in inspected files
→ run trace is written to disk
```

## 非目标

- file writing；
- patch application；
- memory；
- product-level subagents；
- MCP integration；
- sandbox runtime；
- eval dashboard；
- background execution；
- IDE extension。

## 功能验收

| ID   | 标准               | 通过条件                                      |
| ---- | ------------------ | --------------------------------------------- |
| F-01 | CLI starts         | `agent-harness` 打开 TUI                      |
| F-02 | Task submission    | task 出现在 run state 中                      |
| F-03 | Run identity       | 每次 run 有唯一 `runId`                       |
| F-04 | Provider call      | provider 接收 messages 和 tools               |
| F-05 | Tool normalization | provider tool calls 被归一化为 internal calls |
| F-06 | Tool validation    | invalid args 产生 structured error            |
| F-07 | File listing       | file list 保持 stable、bounded、ignore-aware  |
| F-08 | File reading       | safe text files 可以被读取                    |
| F-09 | Search             | 返回 bounded snippets                         |
| F-10 | Git status         | read-only status 可用                         |
| F-11 | Permission prompt  | restricted commands 暂停等待 approval         |
| F-12 | Final answer       | answer 引用 inspected paths                   |
| F-13 | Trace              | JSONL trace exists                            |
| F-14 | Abort              | user 可以 abort run                           |

## 安全验收

| ID   | 标准                 | 通过条件                                         |
| ---- | -------------------- | ------------------------------------------------ |
| S-01 | Path traversal       | `../secret` denied                               |
| S-02 | Symlink escape       | 指向 repo 外部的 symlink denied                  |
| S-03 | Secret files         | `.env`、`.pem`、`.key`、private keys denied 场景 |
| S-04 | Binary files         | binary read denied 场景                          |
| S-05 | Shell string         | product tool 拒绝 shell strings                  |
| S-06 | Destructive commands | destructive commands denied 场景                 |
| S-07 | Output bounds        | large output 带 metadata 截断                    |
| S-08 | No writes            | 不存在 write-capable tool                        |
| S-09 | Redaction            | logs 排除 secrets 和 API keys                    |
