# v0.1.0 Release Contract: Minimal Coding Agent

## Objective

Build a runnable, terminal-first coding agent harness that can inspect a real repository through validated tools and generate a grounded answer without modifying files.

## User journey

```txt
User opens terminal
→ runs agent-harness
→ enters task
→ agent starts run
→ provider requests repo inspection tools
→ tool calls are validated and executed
→ tool results are appended to context
→ agent returns final answer grounded in inspected files
→ run trace is written to disk
```

## Non-goals

- file writing;
- patch application;
- memory;
- product-level subagents;
- MCP integration;
- sandbox runtime;
- eval dashboard;
- background execution;
- IDE extension.

## Functional acceptance

| ID   | Criteria           | Pass condition                                    |
| ---- | ------------------ | ------------------------------------------------- |
| F-01 | CLI starts         | `agent-harness` opens TUI                         |
| F-02 | Task submission    | task appears in run state                         |
| F-03 | Run identity       | each run has unique `runId`                       |
| F-04 | Provider call      | provider receives messages and tools              |
| F-05 | Tool normalization | provider tool calls normalize into internal calls |
| F-06 | Tool validation    | invalid args produce structured error             |
| F-07 | File listing       | stable, bounded, ignore-aware file list           |
| F-08 | File reading       | safe text files can be read                       |
| F-09 | Search             | bounded snippets returned                         |
| F-10 | Git status         | read-only status works                            |
| F-11 | Permission prompt  | restricted commands pause for approval            |
| F-12 | Final answer       | answer cites inspected paths                      |
| F-13 | Trace              | JSONL trace exists                                |
| F-14 | Abort              | user can abort run                                |

## Safety acceptance

| ID   | Criteria             | Pass condition                              |
| ---- | -------------------- | ------------------------------------------- |
| S-01 | Path traversal       | `../secret` denied                          |
| S-02 | Symlink escape       | symlink outside repo denied                 |
| S-03 | Secret files         | `.env`, `.pem`, `.key`, private keys denied |
| S-04 | Binary files         | binary read denied                          |
| S-05 | Shell string         | shell strings denied in product tool        |
| S-06 | Destructive commands | destructive commands denied                 |
| S-07 | Output bounds        | large output truncated with metadata        |
| S-08 | No writes            | no write-capable tool exists                |
| S-09 | Redaction            | logs exclude secrets and API keys           |
