## Fixture demo

```bash
agent-harness --repo fixtures/tiny-ts-repo
```

Task:

```txt
Explain this repository structure and identify the main modules.
```

Expected behavior:

```txt
1. TUI starts.
2. Agent calls list_files.
3. Agent reads package.json.
4. Agent reads README.md.
5. Agent reads src/index.ts.
6. Agent reads src/math.ts.
7. Agent produces grounded final answer.
8. JSONL trace is written.
```
