# v0.1 Demo Script

## Fixture demo

```bash
bun run dev -- --repo fixtures/tiny-ts-repo --task "Explain this repository structure and identify the main modules."
```

Task:

```txt
Explain this repository structure and identify the main modules.
```

Expected behavior:

```txt
1. TUI starts.
2. Agent calls list_files.
3. Agent reads package.json.
4. Agent produces grounded final answer citing package.json and src/index.ts.
5. JSONL trace is written.
```

Abort behavior:

```txt
Press q or Ctrl+C during an active run.
The TUI reports the run as aborted, and core stops further provider/tool work.
```
