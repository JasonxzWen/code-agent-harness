# v0.1 Demo Script

## 前置条件

```bash
bun install
bun run quality
```

## Deterministic smoke demo

```bash
bun run smoke
```

预期结果：

- command exits 0；
- 输出 `smoke passed: <run-id>`；
- trace 写入 `.agent-harness/runs/<run-id>.jsonl`；
- final answer 引用 inspected repository files。

## Fixture repository

Smoke test 使用：

```txt
fixtures/tiny-ts-repo
```

该 fixture 包含一个小型 TypeScript package，因此 agent 可以 inspect real files 而不依赖大型外部仓库。

## Live provider demo

可选：

```bash
OPENAI_API_KEY=... bun run smoke:live
```

如果未设置 `OPENAI_API_KEY`，live smoke 应 skipped，不应作为 release blocker。
